## Usage

### Encryptor
The encryptor takes single line input with the characterset defined in encrypt.cpp key_map() and outputs the encrypter message.

### Decryptor
The encrypted message can be given to decryptor and the decrypted output is given. The given input must be at least 3 characters long.
